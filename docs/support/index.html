Support

Get CouchCTRL paired with your Windows gaming PC and find help when the connection or display setup does not behave as expected.

Requirements

  • An iPhone running the CouchCTRL mobile app
  • A Windows gaming PC running the free Windows Companion
  • Both devices connected to the same local network
  • Steam installed on the PC for Steam Big Picture launch

Pair your iPhone

  1. Install and launch the Windows Companion.
  2. Open its notification-area menu and choose Pair Device.
  3. Enter the displayed six-digit code in the iPhone app.
  4. Test the connection from the Configuration screen.

Before using Couch Mode

Configure the target TV in the Windows Companion and save your normal desktop layout. Activating Couch Mode changes the active Windows display topology and can temporarily disable other monitors.

Troubleshooting

  • Confirm the iPhone and PC are on the same local network.
  • Allow Local Network access when iOS asks.
  • Open Network Diagnostics from the Windows tray menu.
  • Check that the Windows firewall allows the CouchCTRL Companion.
  • Pair the device again if its token was reset.

Contact support

Report a problem through GitHub Issues. Do not include pairing tokens, private network details, logs containing personal information, or other secrets in a public issue.

You can also review existing reports and release information in the CouchCTRL repository.
