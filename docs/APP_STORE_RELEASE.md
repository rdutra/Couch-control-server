# CouchCTRL App Store Release Notes

## Subtitle

Control PC gaming from your couch

## Description opening

CouchCTRL turns your iPhone into a one-tap controller for your Windows gaming PC.
Requires the free CouchCTRL Windows Companion and a shared local network.

## App Review notes

CouchCTRL controls a Windows gaming PC over the local network. To test without hardware, open the app and enable Demo Mode in Settings. Demo Mode simulates a connected Windows Companion, switching between Desktop Mode and Couch Mode without sending network requests.

To test the live pairing flow, install the free CouchCTRL Windows Companion on a Windows PC connected to the same local network. In the Windows tray app, choose Pair Device to display a six-digit pairing code, then enter that code in the iPhone app settings.

No customer account or Apple receipt sharing is required by the Windows Companion.
