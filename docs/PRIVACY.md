# CouchCTRL Privacy Policy

CouchCTRL is designed for local-network control of your own Windows gaming PC.

## Data handled by the iPhone app

- Windows companion address
- Pairing token issued by the Windows companion
- Optional Wake-on-LAN MAC address and broadcast address
- Recent in-app activity status used to explain the last action

This data is stored locally on the device. CouchCTRL does not require an account for version 1.

## Data handled by the Windows companion

- Display and audio configuration
- Desktop restore snapshots
- Pairing tokens for approved devices
- Local diagnostic logs

This data is stored under `%LOCALAPPDATA%\CouchControl` on the Windows PC.

## Network behavior

CouchCTRL communicates over your local network with the Windows companion. Version 1 is LAN-only and does not require a cloud service for pairing or control.
